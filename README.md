# Лабораторна робота №2: візуалізація координатних даних

Репозиторій містить програмну реалізацію другої лабораторної роботи.

## Структура проєкту
* **`lab2.py`** – скрипт на Python, який за допомогою бібліотеки `pandas` зчитує датасет з урахуванням довільних пробілів та табуляцій, а за допомогою `Pillow` створює растрове полотно розміром 960x540 пікселів і виконує перетворення декартових координат у растрові.
* **`result_DS3.png`** – згенероване растрове зображення з нанесеними точками.
* **`Звіт_№2.docx`** – повний текстовий звіт до лабораторної роботи.
